## Course Overview

This course introduces students to network science with a strong emphasis on practical data analysis. We explore network theory, models, and methods used to study social and economic systems. Programming exercises use **Python** (`networkx`, `pandas`, `matplotlib`).

---

## Requirements

This course assumes basic familiarity with Python programming and standard data analysis workflows (e.g. working with pandas, NumPy, and Jupyter notebooks). No prior background in network analysis is required.

It is recommended that students manage course dependencies using a Python virtual environment. Students are expected to be able to install packages using `pip` and work in an isolated Python environment.

Below is an installation guide for the **Python 3.12–based course environment**:

```bash
python3.12 -m venv ans-env
source ans-env/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

## Programming Expectations

Before the first class, work through [`python_expectations.ipynb`](python_expectations/python_expectations.ipynb) (also available as [PDF](python_expectations/python_expectations.pdf) / [HTML](python_expectations/python_expectations.html)) -- a short, non-network checklist covering the level of Python and pandas we assume from day one: loops, functions, lists, dictionaries, reading a table, filtering, aggregation, and basic plotting. If any part of it looks unfamiliar, brush up before class.
